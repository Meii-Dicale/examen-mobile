EventEase, l'app des membres et bénévoles

Les écrans du prototype React Native, avec la palette choisie : une couleur principale pour les actions, une couleur d'accent pour le bouton + et la météo. Les données affichées sont des exemples, comme le seed de la base SQLite.

Thème de l'app

Palettes de couleurs

Palette retenue : Prune & pêche. Les autres restent cliquables pour comparer, et toute la maquette (logos, écrans, clair et sombre) se met à jour. Les quatre nouvelles palettes respectent le niveau AA des règles d'accessibilité WCAG en mode clair et en mode sombre. Le tableau en dessous montre les contrastes calculés pour la palette choisie.

Usage dans l'appClairSombre

Seuil AA : 4,5:1 pour le texte, 3:1 pour les icônes et les points du calendrier. La couleur d'accent sert seulement de fond (bouton +, météo), jamais de couleur de texte sur fond clair, car elle n'est pas assez contrastée pour ça.

Propositions de logo

Trois pistes, avec les mêmes couleurs. Chacune est montrée sur fond clair, sur le fond du splash et en icône d'application. La piste B, choisie, est celle qu'utilisent les écrans ci-dessous.
